# Local Setup

## Prerequisites

- Node.js (v18 or higher recommended)
- Python 3.9 or higher
- Git

---

## Step 1: Clone the Repository

```bash
git clone https://github.com/vishwasvarma/Shortlyst.git
cd Shortlyst

python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py

cd frontend
npm install
npm start
cd backend
```
