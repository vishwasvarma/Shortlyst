# Shortlyst

## Project Title & Description
**Shortlyst – JD‑Aware Resume & Profile Screening Web Application**

Shortlyst is a JD‑aware resume screening web application that helps recruiters and hiring teams **quickly shortlist the right candidates** based on a specific Job Description (JD).

Instead of using generic keyword filtering, Shortlyst evaluates resumes **relative to the JD** by combining:
- Rule‑based screening (for transparency and fairness)
- AI‑based analysis (for deeper, JD‑conditioned insights)

The system automatically:
- 🟢 Shortlists strong matches  
- 🔴 Rejects clear mismatches  
- 🟡 Flags borderline candidates for human review  

This reduces recruiter workload, minimizes false rejections, and keeps humans in the loop only when necessary.
